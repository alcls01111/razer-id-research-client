Privacy policy

Last updated: November 17, 2026.

This static website describes an OAuth research prototype. It has no application server, account registration, analytics, or forms. Public sign-in is not offered.

Authorized tests use only the project owner's Razer ID account. If an OAuth flow is enabled later, the test client may receive the owner's identity claims and authorization tokens for local verification. The website does not publish those values or intentionally retain them after a test. The test client will not request other users' data.

GitHub Pages hosts this site and may process ordinary web request information under GitHub's privacy statement. Razer handles data entered on its own services under its policies.

For privacy questions, open an issue in the project repository. Do not include passwords, tokens, or personal data in a public issue.
